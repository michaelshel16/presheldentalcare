# Preshel Dental Care — Artisanal Sienna UI

React + Vite + Tailwind CSS v4 website. The existing page routes and broad content structure are retained, with a consistent Artisanal Sienna palette and improved text contrast.

## Run locally
1. Extract the ZIP.
2. Open the extracted `preshel-dental-sienna` folder in VS Code.
3. Open Terminal in VS Code.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed by Vite (usually http://localhost:5173).

## Routes
- `/` — Home
- `/services` — Services
- `/aboutpage` — About
- `/contact` — Contact
- `/appointment` — Appointment request
- `/adminpage` — Admin sign-in placeholder

## Theme
- Espresso: `#29211D`
- Sienna: `#A93400`
- Deep Sienna: `#852A04`
- Warm Sand: `#EDE4DC`
- Champagne: `#E8B99C`
- Warm Canvas: `#FAFAFA`

## Important
Appointment and contact forms are frontend demonstrations only. They do not send, save, or book patient information. Admin authentication is not implemented. Confirm service availability and clinic details before deployment.
